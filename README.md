# DigitalBank Landing Page

A responsive digital banking landing page built as part of the [Frontend Mentor DigitalBank Landing Page Challenge](https://www.frontendmentor.io/challenges/digital-bank-landing-page-WaUhkoDN).

The goal of this project was to recreate a modern banking website with a focus on responsive layouts, clean component structure, accessibility, and polished UI interactions.

## What I Learned

This project helped improve my understanding of building responsive layouts that adapt naturally across multiple screen sizes.

Some key areas I practiced:

- Managing complex responsive positioning with Tailwind breakpoints
- Creating overlapping hero layouts using relative and absolute positioning
- Building reusable React components for page sections
- Handling theme-based UI changes
- Improving accessibility through semantic HTML and ARIA attributes
- Balancing visual effects with maintainable code

One of the main challenges was positioning the hero mockup image correctly across mobile, tablet, and desktop layouts while maintaining the intended design.
